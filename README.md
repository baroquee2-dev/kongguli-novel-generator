# KongGuLi-孔固力自動小說生成器 🧱

> **靈活多層式 AI 創作系統** — 拒絕死板狀態機，回歸最自然直觀、層次分明、架構穩如「孔固力（混凝土）」的故事創作工坊。

---

## 🌟 核心理念與 4 層創作架構

專為小說創作者打造的**簡約、非程式化流程**輔助創作系統。世界觀、人物性格、場景氛圍層層遞進，讓 AI 生成的正文有深度、有條理且不偏離設定：

```text
第 1 層：小說主體 (書名 / 題材風格 / 基調 / 核心主線 / 宏觀世界觀)
   ↓
第 2 層：世界地點 (大地點 ➔ 附屬細節子場景 / 建築氛圍 / 隱密角落)
   ↓
第 3 層：角色陣容 (姓名 / 定位 / 身世性格 / 外貌細節 / 角色頭像立繪卡)
   ↓
第 4 層：章節創作 (大綱細綱 / 登場人物與地點快速勾選 / 登場角色一字排開展示 / 一鍵 AI 融合正文 / 順著情節續寫)
```

---

## ✨ 核心特色

1. **主流與開源 AI 自由連線 (BYOK / 零綁定)**：
   - **OpenRouter**：支援海量模型自由切換，內建**即時關鍵字搜尋**、模型清單本機快取與自選推薦。
   - **Google Gemini**：支援 `gemini-2.5-flash`、`gemini-1.5-pro` 等。
   - **OpenAI**：支援 `gpt-4o`、`gpt-4o-mini`、`o1` 等。
   - **Anthropic Claude**：支援 `claude-3-5-sonnet` 等。
   - **本地 / 自訂模型 (Ollama)**：支援相容 OpenAI 介面的本機模型（如 `http://localhost:11434/v1`）。
   - 內建一鍵連線測試與狀態診斷。

2. **SillyTavern 風格閱讀渲染**：
   - **對話台詞**：雙引號 `“...”` 或 `"..."` 自動以暖橘色/琥珀色高亮標記，對白清晰生動。
   - **動作與背景描繪**：以單星號 `*...*` 包覆的動作描寫，自動以優雅斜體紫灰色呈現，並自動隱藏標點星號，營造高度沉浸感。

3. **章節創作全寬沉浸排版 & 登場角色畫廊**：
   - 工作區最大化寬度排版，左側聚焦章節列表，右側專注編輯閱讀。
   - 勾選登場角色後，頂部以**橫向卡片畫廊一字排開**，角色立繪、定位與性格即時展示在眼前。
   - 提供專屬**字體大小調節器**（13px ～ 22px），偏好設定自動持久化，不影響其他介面元素。

4. **每一層皆支援手寫 ＋ AI 輔助發想**：
   - **第 1 層**：手寫主線，或給一句初步想法，AI 自動激盪出書名與主體架構。
   - **第 2 層**：可手動新增大地點與子場景，或點擊「AI 發想地點」一鍵生成場景群。
   - **第 3 層**：手動設計人物卡或 AI 一鍵發想角色陣容，支援本機上傳圖片立繪與即時預覽。
   - **第 4 層**：自由編排章節，動態勾選登場人物與場景，點擊「✨ 生成完整章節」，AI 將自動將所有背景、性格、地點氛圍與前章脈絡融為一體。

5. **純本地資料持久化與一鍵匯出**：
   - 所有資料存於本機 `data/novels/*.json`，注重隱私，不依賴雲端資料庫。
   - 支援「一鍵匯出全書」為標準 Markdown / TXT 文章檔。

## 🚀 快速啟動

### 方式一：Windows 一鍵啟動 (最推薦)
在專案根目錄下雙擊執行：
```bat
run.bat
```
*(或在 PowerShell 中執行 `./run.ps1`)*

腳本將自動建立 Python 虛擬環境、安裝依賴套件，並同步啟動後端與前端，最後自動開啟瀏覽器前往 `http://localhost:5173`。

---

### 方式二：手動啟動

#### 1. 後端 (FastAPI)
```bash
# 建立並啟用虛擬環境
python -m venv .venv
.\.venv\Scripts\activate

# 安裝依賴
pip install -r backend/requirements.txt

# 啟動後端 API (Port 8000)
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload
```

#### 2. 前端 (React + Vite)
```bash
cd frontend
npm install
npm run dev
```

開啟瀏覽器造訪：`http://localhost:5173`

---

## 🛠️ 技術架構

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS + Lucide React
- **後端**：Python FastAPI + Uvicorn + Httpx + Pydantic
- **儲存**：本地 JSON 檔案儲存 (`data/`)，便於手動備份與版本控制
